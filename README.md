Подмодуль модуля событий, балансирующий их второй половине игры.
Использует довольно "жадный" алгоритм.
Хотя файл example_data нужен только для генерации тестовых данных, в нем также содержится класс Event обозначающий событие, часть кода основывается на нем. А именно на полях id и bal. Поле id обозначает порядковый номер события, а bal - список суммарных влияний решений данного события разбитые по показателям.
Все "print" инструкции опциональны и носят скорее отладочный характер.

Программа разбита на отдельные функции для удобства реализавции и восприятия
Главная функция - balancer
  на вход принимает следющие параметры:
    -текущий раунд
    -всего раундов
    -список возможных событый
    -список произошедших событий
  на выходе:
    -либо строка с ошибкой
    -либо список ID событый которые подходят
  она же вызывает остальные функции в своей работе
  А именно:
    calc_curr_bal - функция отвечающая за подсчет текущего состояния показателей (здесь имеются ввиду не показатели королевства, а решений)
      на вход принимает следющие параметры:
        -список произошедших событый
      на выходе:
        -список из 4 значений int
    analyzer - функция анализирующая последовательность на "аномальность"
       на вход принимает следющие параметры:
        -список из 4 значений int
      на выходе:
        -либо False, если отклонение в пределах нормы
        -либо список из двух int где первый - позиция аномального параметра,а второй - его значение
    finder - функция поиска подходящих событий
      -на вход принимает следющие параметры:
        -позиция аномально параметра
        -значение аномального параметра
        -список возможных событий
      на выходе:
        -список подходящих ID
